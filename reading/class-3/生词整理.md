## 五、同义替换汇总（阅读重点）

| 意思 | 同义词 / 同义表达 |
|------|------------------|
| 方法 | **approach = method = way = means** |
| 仅仅 | **merely = only = solely** |
| 特定的 | **certain = particular = specific** |
| 重要的 | **significant = crucial = essential = important = vital** |
| 似乎 | **seem to = appear to** |
| 进行 | **carry out = conduct = perform = do** |
| 减少 | **diminish = decrease = reduce = decline** |
| 像 | **resemble = look like = be similar to** |
| 意识到 | **be aware of = realize = notice** |
| 被称为 | **be known as = be called = be referred to as** |
| 大量的 | **a considerable amount of = a large amount of = plenty of** |
| 补偿 | **compensate = make up for = offset** |
| 阻止 | **inhibit = prevent = hinder = stop** |
| 引导 | **channel = direct = guide** |
| 稀有的 | **scarce = rare = in short supply** |

## 六、易错点提醒

1. **term 不要写成 trem**（拼写错误）
2. **solely 不要写成 soly**（拼写错误）
3. **be known as 不要写成 be know as**（缺少过去分词）
4. **considerable** 是形容词，**considerably** 是副词
5. **approach** 既可作名词也可作动词：*a new approach* / *to approach the problem*
6. **domestic** 多义：国内的、家庭的、驯化的，看上下文判断

## 七、题型要点回顾

### 1. 特殊词匹配题
- 细节题，顺序出现
- 人名首次全称，后面可能改成单姓或代词
- 存在复选：一个选项可能选 2-3 次
- 做题步骤：划定位词 → 统计次数 → 从低频特殊词开始 → 对应同义替换 → 排除答案

### 2. 段落信息匹配题
- 乱序出现，题干抽象，原文具体
- 多选情况：1 个选项可能选 2 次
- 和有选项填空题的复选规则一致
