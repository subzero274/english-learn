## 主要问题诊断

1. **拼写基本功薄弱**：possible、college、passport、library、otherwise、photocopying、magazines 等高频词反复出错，直接影响填空题得分。
2. **功能词弱读漏听严重**：a / the / it / to / 'll / 've / our 等弱读形式大量丢失。
3. **连读与缩略辨识不足**：it's possible / you'll need / that's why / you're a student 等连读反应慢。
4. **数字与货币表达不敏感**：£125 per year、£25、£1.50、£5 per week、5p/40p a sheet、twenty-four/forty-eight hours 频繁写错单位或漏听 per/hour/thereafter。
5. **专有名词拼写困难**：Westerley College、Jefferson's steel factory、Grantingham、The Guardian / Observer / Independent / Times。
6. **后半段信息量增大后正确率骤降**：电脑预订、复印、写作课等话题的生词和语速导致 S1 后半段大量丢分。
