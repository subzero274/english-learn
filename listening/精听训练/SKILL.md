# 精听批改 Skill

> 用于统一批改 `listening/精听训练/` 目录下的听写材料，并生成可复盘的结构化报告。

---

## 1. 输入要求

每次精听练习提交在一个独立的子目录中，命名规则：

```
050301/
├── detail.md     # 听写原文对照
├── 050301.mp3    # 对应音频文件（可选）
├── 050301-correction.md   # 批改报告（自动生成）
└── 050301-errors.json     # 错误单词本（自动生成）
```

早期材料可能直接放在 `listening/精听训练/` 根目录下（如 `050201.md`），新建议统一使用子目录方式，便于管理同一材料的音频、批改报告和错误单词本。

文件内格式：`detail.md` 每段包含 **听写行** + **标准原文行**，用空行分隔。例如：

```markdown
Good monring your collage Library how can i help you
Good morning your college library how can I help you

i was wandring if the possibe to join the library
I was wondering if it's possible to join the library
```

如果某句没有标准原文，会在批改时根据雅思真题或上下文推断补充。

---

## 2. 批改维度

对每个句子从以下 5 个维度分析：

| 维度 | 说明 | 示例 |
|------|------|------|
| **漏听** | 原文有、听写没有的功能词或实词 | a, the, it, to, 'll, our |
| **拼写错误** | 词形接近但拼写不正确 | possibe → possible |
| **听错/音近混淆** | 音近但词义不同的词 | dress → address |
| **语法错误** | 时态、单复数、词性、人称错误 | tell → told, student → students |
| **多写/幻听** | 听写中多出的词或完全听错的词 | the → them, forwzend |

---

## 3. 评分标准

每句按正确词数 / 参考词数计算正确率，然后按以下标准评级：

| 等级 | 正确率 | 含义 |
|------|--------|------|
| **A** | ≥ 90% | 优秀，基本掌握 |
| **B** | 80-89% | 良好，少量拼写/漏听 |
| **C** | 70-79% | 中等，有明显功能词或拼写问题 |
| **D** | 60-69% | 需加强，连读/弱读辨识不足 |
| **F** | < 60% | 薄弱，建议重新精听该句 |

**综合评分** = 所有句子正确词数之和 / 所有句子参考词数之和，再按同一标准评级。

---

## 4. 输出格式模板

每次批改生成两个文件：

1. `{材料目录}/{材料编号}-correction.md` — 完整批改报告
2. `{材料目录}/{材料编号}-errors.json` — 错误单词/短语本（便于导入 Anki、Quizlet 等工具复习）

例如：
- `050301/050301-correction.md`
- `050301/050301-errors.json`

### 4.2 错误单词本 `{原文件名}-errors.json`

从批改报告中提取真正因「不会/不熟」而错的词，排除简单功能词（a/the/it/to）和已掌握的简单词，统一使用以下 JSON 格式：

```json
[
  {
    "phrase": "get along",
    "phonetic": "/ɡet əˈlɒŋ/",
    "pos": "v. phrase",
    "meaning": "相处；进展",
    "example": "Do you get along with him?"
  }
]
```

字段说明：

| 字段 | 说明 | 示例 |
|------|------|------|
| `phrase` | 正确单词或短语 | `passport photo` |
| `phonetic` | IPA 音标 | `/ˈpɑːspəʊt ˈfəʊtəʊ/` |
| `pos` | 词性 | `n.`, `v.`, `adj.`, `n. phrase` |
| `meaning` | 中文释义 | `护照照片` |
| `example` | 来自原文或仿写的例句 | `You'll need two passport photos.` |

入选标准：
- 反复拼错的词
- 因听不懂而完全写错的实词
- 对做题/理解关键的短语搭配
- 不收入：简单功能词、已掌握的基础词、纯专有名词（如人名 Grantingham 可单独记录）

---

## 5. 批改流程

1. **读取文件**：按空行分组，识别每段听写与原文。
2. **补齐原文**：若某段缺少标准原文，根据雅思真题或上下文推断。
3. **词级对比**：清洗大小写和标点后逐词对比，标记 equal / insert / delete / replace。
4. **错误分类**：根据编辑距离和语义判断是拼写错误、听错还是漏听。
5. **计算正确率**：正确词数 ÷ 参考词数。
6. **生成报告**：按模板输出 Markdown 批改报告。
7. **生成错误单词本**：从批改报告中筛选核心错误词，输出为 `{原文件名}-errors.json`。

---

## 6. 注意事项

- **不计入错误的项**：大小写差异（除非专有名词）、标点缺失、英式/美式拼写差异。
- **数字统一**：阿拉伯数字与英文数字视为等价（12 / twelve）。
- **缩略形式**：I'll = I will，it's = it is / it has，按原文标准形式判定。
- **货币符号**：£1.50 / 1.50 / 1.5 视为等价，但单位（per year / per week）必须正确。

---
